# docs mode

**Goal:** accurate, readable pages in a repository that holds writing, not software (user's decision, 2026-11-01; added for the study notebook, where `build` does not fit).
**Who decides:** agents decide wording, structure, examples and where a point goes. The user decides claims, scope and anything published under their name.

## Agent steps

1. Follow the project's page format (its `README.md`); keep to its length and section rules.
2. When the user asks a question about a page, add it to the page's question log in the same turn and fold the answer into the section it belongs to, with an example when the point is abstract. The user should not have to ask for this.
3. Work on a branch with a pull request, as the tier says. Links are checked before the PR is opened.

## User steps

Read the page, ask what it does not say, and overrule any claim. A question you had to ask is a defect in the page.

## Where things live

The page format and any project rules live in the project, so the repository makes sense on its own.
