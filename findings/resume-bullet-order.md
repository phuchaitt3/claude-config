# Resume bullet order within one entry

- **Question:** Inside one job or project entry, are bullets ordered by significance (impact, relevance) or by the order things happened, and must a bullet's terms be introduced before it uses them?
- **Finding:**
  - Entries (jobs) go in reverse-chronological order; the bullets inside one entry do not. Guides say to rank bullets by impact or relevance to the target job and put the strongest first, not the earliest event.
  - University career centres give the same rule for projects: the most relevant bullets first, tailored to the posting (UC San Diego: most impressive accomplishments first, since recruiters skim).
  - A reorder after drafting is normal ("write them all out, then arrange").
  - *Checker's inference:* no source covers terms used before they are defined. A strongest-first order means the top bullet is read with no earlier context, so it has to carry its own definitions (expand or qualify a term inline, e.g. "RAG-retrieved contexts"). Moving a weaker, introductory bullet to the top to supply context would break the strongest-first advice; defining inline keeps both.
