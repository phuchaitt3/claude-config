# Coding and CS basics versus ML theory in entry-level ML and AI interviews

- **Question:** In entry-level ML and AI engineer interviews and tests, are coding and CS fundamentals or ML theory asked more, and what ML basics recur?
- **Finding:**
  - *Both are tested; coding usually comes first.* Prep guides say the early screen is typically a live coding challenge on data structures and algorithms, and that most coding rounds focus on those rather than on ML tasks. ML theory is described as still a core component: interviewers expect candidates to understand the models they use. One entry-level breakdown lists three parts: coding (Python data structures, algorithms), ML fundamentals (loss functions, regularization, evaluation) and basic system design. Loops are often described as ML concepts, coding, system design and behavioural rounds.
  - *Recurring ML basics.* Gradient descent (batch, mini-batch and stochastic variants; learning rate; Adam), precision and recall (when to favour each; F1 over accuracy for imbalanced classes), overfitting (what it is, regularization, cross-validation). A fresher-level guide contrasts a strong answer (optimizer, loss, learning rate, variants) with a weak vague definition.
  - *Dissent.* One source argues candidates actually fail on software engineering, data pipelines and infrastructure, not ML theory.
  - *OS, networking and SQL.* No source confirmed these for the entry-level AI assessments of Vietnamese firms searched (FPT, Viettel, VNG); an FPT report names only an RNN versus LSTM question and FPT's new AI skills test has no published syllabus. Treat them as plausible, unverified.
  - *Not found.* No hiring data specific to new-graduate AI engineers, and no source weighs CS basics against ML theory by share of questions. Any ratio would be the checker's inference.
- **Evidence strength:** *anecdotal.* Prep-site guides and one candidate report; no survey or hiring-data study.

## One Vietnamese employer: VNG's test and interview reports (added 2026-11-27)

- **Finding** (all *anecdotal* or search summaries, mostly old; standard: findings/entry-level-ml-interview-emphasis, checked 2026-11-27):
  - A 2024-07 forum opener describes the AI intern process the poster expected: a multiple-choice test mostly on data science, a coding interview, then a behaviour round. No reply confirmed it.
  - Fresher test (posts from 2021-2023): about 25-30 multiple-choice questions in 60 minutes, mostly data structures, algorithms, complexity and code reading; one poster put the pass mark near 60-70% and called the interview the harder stage.
  - A 2018 careers blog gives a one-hour onsite interview with 2-3 interviewers and results within 2 weeks; one undated candidate quote there lists data types, data structures and design patterns.
  - No report was found for VNG's 2026 AI residency, which a university announcement calls the first cohort (search summary).
- **Evidence strength:** *anecdotal*; no first-hand report of a recent VNG AI interview.
